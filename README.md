## 📊 Sobre o Projeto / About the Project

### 🇧🇷 Português
Este repositório contém o código-fonte, os ambientes de teste e os scripts de benchmark desenvolvidos para o meu Trabalho de Conclusão de Curso (TCC) em Ciência da Computação na USP. 

O objetivo principal desta pesquisa foi investigar, mensurar e comparar os gargalos de desempenho e métricas de execução entre **WebAssembly (Wasm)** e **JavaScript** em ambientes mobile baseados em **Linux**. A análise foca em entender o comportamento dessas tecnologias sob restrições severas de hardware, avaliando fatores como tempo de processamento, eficiência de memória e consumo de recursos.

### 🇺🇸 English
This repository contains the source code, test environments, and benchmark scripts developed for my Bachelor's Thesis (TCC) in Computer Science at USP.

The core objective of this research was to investigate, measure, and compare performance bottlenecks and execution metrics between **WebAssembly (Wasm)** and **JavaScript** within **Linux-based mobile environments**. The analysis focuses on understanding how these technologies behave under hardware constraints, evaluating factors such as processing time, memory efficiency, and resource utilization.
